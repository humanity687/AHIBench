# seed 目录格式

用 `realtest/prompt_story_seed.md` 的提示词让另一个 AI 生成内容，按以下格式存入本目录：

| 文件 | 内容 |
|---|---|
| `story.txt` | 故事正文（3500~4500 字，段落间空行分隔，无标题/注释） |
| `facts.md` | 事实表：Markdown 表格 `| id | 问题 | 必含片段 | 类别 |`，30~40 条，必含片段逐字摘自原文 |
| `names.txt` | 人物名单，每行一个名字 |

当前 `placeholder_*.txt` 为冒烟占位种子（供测试链路用），正式运行前请替换为 AI 生成版。
